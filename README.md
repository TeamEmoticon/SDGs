# 안심글

문자나 인터넷 글을 붙여넣거나 주소를 입력하면 사기·피싱 위험을 쉬운 말로 알려주는 SDGs 디지털 안전 도우미입니다.

## 현재 상태

- 핵심 흐름: 문자·글 또는 인터넷 주소 입력 → 분석 중 상태 → 위험 단계와 권장 행동 확인
- 저장: 원문 대신 안전한 결과 요약만 브라우저 로컬 기록에 저장
- 배포 대상: Netlify 환경
- 현재 작업 브랜치: `feat/ui-cleanup-phase1`
- 외부 분석 전환: Groq/PostgreSQL 대신 Gemini와 Netlify Function을 사용하는 구조로 전환됨

## 이번 작업에서 반영한 UI

- 고령 사용자를 위해 기본 글자 크기를 18px로 조정하고 20px, 22px 단계의 글자 크기 조절을 제공
- 글자 크기 설정을 `ansim-font` 키로 저장해 다시 방문해도 유지
- `고대비 켜기` 버튼과 `일반 화면으로` 버튼을 제공하고 `ansim-contrast` 키로 설정을 저장
- 배경, 텍스트, 테두리, 버튼, 위험 단계 색상을 의미 기반 CSS 변수로 통일
- 파란색 그라데이션 헤드라인과 장식성 배경을 제거하고 고대비 텍스트 중심으로 변경
- 입력 화면의 중첩 카드를 줄이고 큰 입력 영역, 큰 버튼, 직접적인 오류 안내를 적용
- 최근 확인 기록을 카드 목록 대신 구분선 기반 목록으로 변경
- 결과 화면을 위험 판정, 지금 할 일, 쉬운 요약으로 먼저 보여주도록 계층화
- 위험 신호, 주의 문장, 개인정보 정보는 `details` 펼쳐보기로 정리
- 위험·고위험 결과의 위험 신호는 기본으로 펼쳐지고 안전·주의 결과는 접힌 상태로 시작
- 360px 모바일 폭에서 가로 넘침이 발생하지 않도록 확인

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.

## 검증 명령

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

현재 검증 결과:

- TypeScript 검사 통과
- ESLint 통과
- 테스트 10개 통과
- Next.js 프로덕션 빌드 통과
- 브라우저에서 고대비 모드, 글자 크기 조절, 분석 결과 흐름 확인
- 브라우저 360px 폭에서 가로 스크롤 없음 확인

## 프로젝트 규칙

- `main`은 발표 가능한 안정 버전, `develop`은 통합 브랜치로 사용
- 기능 작업은 `feat/` 또는 `fix/` 브랜치에서 진행
- force push, `git reset --hard`, 기존 커밋 기록 재작성 금지
- 명시적인 요청 없이 merge 또는 push하지 않음
- 새 라이브러리를 임의로 추가하지 않음
- UI와 데이터 로직을 분리하고 기존 타입과 인터페이스를 재사용
- API 키와 비밀값을 코드에 하드코딩하지 않음
- 모바일 최소 지원 폭은 360px

## 협업 시 주의할 점

- 분석 API와 저장소의 데이터 계약을 임의로 바꾸지 않습니다.
- 분석 결과에 `riskLevel`, `riskScore`, `recommendation`, `signals`, `ai`, `mask`가 있어야 결과 화면이 정상 동작합니다.
- 원문 저장을 추가하지 않습니다. 최근 기록에는 안전한 결과 요약만 저장합니다.
- API나 저장 실패 시 성공으로 보고하지 않고 오류 상태를 유지합니다.
- 작업 완료 보고에는 구현 내용, 변경 파일, 테스트·빌드 결과, 가정, 연결 필요 사항, 남은 위험을 포함합니다.

## 남은 위험

- 현재 작업 변경 사항은 아직 커밋하거나 원격 저장소에 push하지 않았습니다.
- Netlify 실제 배포 환경에서 Gemini 환경 변수와 Function 연결은 별도 배포 확인이 필요합니다.
- 자동화된 브라우저 E2E 테스트는 없으며, 이번 확인은 로컬 브라우저 수동 QA로 진행했습니다.
