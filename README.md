안심글

«고령층과 디지털 소외계층이 의심 문자 속 보이스피싱·스미싱 위험을 쉽게 이해하고, 안전한 다음 행동을 선택하도록 돕는 웹 서비스입니다.»

프로젝트 소개

디지털 금융과 모바일 서비스가 일상화되었지만, 복잡한 문자와 기관 사칭 메시지를 판단하기 어려운 사용자는 보이스피싱과 스미싱 피해에 더 쉽게 노출될 수 있습니다.

안심글은 사용자가 받은 문자나 메신저 내용을 붙여넣으면 다음 내용을 제공합니다.

- 개인정보 자동 마스킹
- 보이스피싱 위험 신호 탐지
- 4단계 위험도 표시
- 어려운 내용을 쉬운 말로 요약
- 위험하다고 판단한 구체적인 이유
- 상황에 맞는 대응 행동 안내
- 최근 분석 결과의 기기 내 저장
- 큰 글씨와 고대비 화면 지원

SDGs 연계

고령층의 정보 격차(진실에 대한)를 줄이는것과 연계가 됩니다


핵심 분석 흐름

사용자 입력
→ 입력 형식과 길이 검증
→ 전화번호·계좌번호·인증번호 등 개인정보 마스킹
→ 규칙 기반 보이스피싱 위험 신호 탐지
→ 명백한 사기 조합이면 규칙 결과 즉시 생성
→ 추가 설명이 필요한 경우 Gemini 최대 1회 호출
→ AI 응답의 인용문과 형식 재검증
→ 규칙 엔진이 최종 위험 점수와 등급 계산
→ 위험 이유와 권장 행동 표시

위험도 판단 원칙

최종 위험도는 AI가 아닌 규칙 엔진이 결정합니다.

주요 탐지 항목은 다음과 같습니다.

- 가족·지인·경찰·검찰·금융기관 사칭
- 송금, 계좌이체, 상품권 구매 요구
- 비밀번호, 인증번호, 신분증 정보 요구
- 앱 설치, 화면 공유, 원격제어 요구
- 링크 접속과 개인정보 입력 유도
- 체포, 계정 정지, 처벌 등 위협
- 즉시 또는 오늘 안에 처리하라는 재촉
- 다른 사람에게 알리지 말라는 요구

단일 단어만으로 위험을 확정하지 않고, 여러 신호의 조합과 요구 맥락을 함께 확인합니다.

위험 단계

단계| 사용자 안내
낮음| 뚜렷한 보이스피싱 신호가 적습니다
주의| 한 번 더 확인해 주세요
위험| 보이스피싱이 의심됩니다
고위험| 보이스피싱 위험이 매우 높습니다

낮은 단계도 메시지의 안전을 보장하지 않습니다. 금전이나 개인정보를 요구받았다면 문자 속 연락처가 아닌 공식 대표번호를 통해 다시 확인해야 합니다.

AI의 역할

Gemini는 다음 작업만 보조합니다.

- 어려운 문장을 쉬운 한국어로 요약
- 발신자가 요구하는 행동 분류
- 사칭 유형 분류
- 원문에 존재하는 의심 문구 추출

Gemini는 위험 점수와 최종 등급을 결정하지 않습니다.

API 키 누락, 호출 제한, 시간 초과 또는 잘못된 응답이 발생해도 규칙 기반 분석 결과를 반환하도록 설계했습니다.

개인정보 보호

- 전화번호, 계좌번호, 인증번호, 주민등록번호, 카드번호 등을 분석 전에 마스킹합니다.
- 최근 기록에는 원문을 저장하지 않습니다.
- 최근 기록은 사용자의 브라우저 "localStorage"에만 저장됩니다.
- API 키는 클라이언트 코드가 아닌 서버 환경변수에서만 사용합니다.
- 실제 환경변수 파일은 제출물과 Git 저장소에 포함하지 않습니다.

범위 밖 입력

안심글은 보이스피싱과 스미싱 위험 확인에 집중합니다.

뉴스, 건강정보, 정책 주장, 과제 또는 일반 문장이 입력된 경우 사실 여부를 억지로 판정하지 않으며, 보이스피싱 분석 범위와 다르다는 안내를 제공합니다.

기술 스택

- Next.js 16
- React 19

- Tailwind CSS 4
- Gemini 3.1 Flash-Lite

- 브라우저 Local Storage
- Node Test Runner

만들어서 실행한 구조

1. 의존성 설치

npm ci

2. 환경변수 설정

프로젝트 루트에 ".env.local" 파일을 만들고 다음 값을 설정합니다.

GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.1-flash-lite

보안상 실제 API 키는 제출 파일에 포함되지 않았습니다.

API 키가 없어도 규칙 기반 분석은 작동하도록 설계하였습니다.

3. 개발 서버 실행

주요 폴더

src/
├─ app/                 Next.js 화면 및 API Route
├─ components/          입력·결과·최근 기록 UI
├─ lib/                 규칙, 점수, 개인정보 마스킹, URL 검사
├─ services/            전체 분석 흐름 및 Gemini 연동
└─ storage/             최근 분석 기록 관리

tests/                   규칙·분석 흐름·회귀 테스트
netlify/functions/       Netlify 서버 함수 어댑터
docs/                    아키텍처와 판단 로직 문서

한계

- 분석 결과는 참고용이며 보이스피싱 여부를 완전히 보장하지 않습니다.
- 새로운 사기 표현이나 우회 문구를 놓칠 수 있습니다.
- 정상 안내와 사기 문자가 비슷한 표현을 사용하면 오탐이 발생할 수 있습니다.
- 의심스러운 메시지는 반드시 공식 기관이나 평소 알고 있던 연락처를 통해 다시 확인해야 합니다.
