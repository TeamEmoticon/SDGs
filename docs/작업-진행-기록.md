# 안심글 — 작업 진행 기록

> SDGs 정보격차 해소 서비스. 문자·인터넷 글의 사기·피싱 위험을 어르신도 알기 쉽게 알려주는 웹앱.
> 이 문서는 지금까지의 작업 단계와 최근 동기화·검증 결과를 정리한 것이다.

## 1. 개요

- **이름**: 안심글 (SDGs 디지털 안전 도우미) — SDG 16·10·9 실천 목표
- **대상**: 어르신·디지털 소외계층
- **하는 일**: 붙여넣은 문자/URL을 분석해 **위험 4단계(안전·주의·위험·고위험)**를 쉬운 말로 안내
- **기술 스택**: Next.js 16 (App Router, React 19) · TypeScript · Tailwind CSS 4 · Gemini(3.1 Flash-Lite) · Netlify Functions
- **저장소**: `TeamEmoticon/SDGs`, 브랜치 `feat/ui-cleanup-phase1`

## 2. 아키텍처

**단일 페이지 상태 전환형** — `src/app/page.tsx` → `src/components/Analyzer.tsx`가 `입력 → 분석 중 → 결과` 화면을 상태로 전환한다(별도 라우팅 없음).

**분석 파이프라인** (`src/app/api/analyze/route.ts` / `netlify/functions/analyze.ts` 공통 서비스):
1. **개인정보 마스킹** (`src/lib/masking.ts`) — 전화·계좌·인증번호·주민번호·카드번호를 ●로 가림
2. **규칙 기반 위험 신호** (`src/lib/rules.ts`) — 사칭·협박·송금·개인정보·미끼·링크·조급함 등 15개 규칙
3. **AI 요약·분류** (`src/services/gemini.ts`) — 쉬운 말 요약·정보 유형 분류·의심 문구 추출. **키가 없거나 실패하면 규칙 기반으로 graceful fallback**(`ai.used:false`, HTTP 200)
4. **위험 점수·등급 계산** (`src/lib/risk.ts`) — 규칙 신호 가중치 + AI 보조 신호로 0~100 점수와 4단계 등급 산출

**로컬 최근 기록** (`src/storage/analysisHistory.ts`, 화면은 `src/components/RecentHistory.tsx`):
- 이 기기 `localStorage`에만 저장(키 `ansim-analysis-history.v1`), 최신순 **최대 20개**
- **개인정보 비저장** — 저장 타입은 `Omit<AnalysisResult,"maskedText">`, preview는 마스킹된 80자만. 원문·마스킹 전 개인정보는 저장하지 않음
- 중복 저장 방지, 용량 초과 시 절반만 재기록하는 폴백, JSON 손상·저장소 차단 시 기록 기능만 비활성화하고 분석은 유지

## 5. 검증 중 발견하고 해결한 문제 — dev 스타일 미적용

동기화 직후 dev 서버에서 Tailwind CSS가 전혀 적용되지 않는 문제가 있었다.

- **증상**: 컴파일된 `globals.css`가 `unparsable`, 모든 유틸리티 클래스 무효
- **원인**: dev 로그의 `Can't resolve 'tailwindcss' in '<프로젝트 상위 폴더>'` — 프로젝트 **상위 폴더에 있던 빈 `package-lock.json`**(`"packages":{}`)이 Turbopack의 작업 루트를 상위로 오인하게 만들어, `@import "tailwindcss"`가 엉뚱한 위치에서 패키지를 찾다 실패
- **조치**: 상위 폴더의 stray lockfile을 옆으로 치우고(`package-lock.json.bak`) `.next` 캐시 정리 후 재시작 → CSS 정상 컴파일, 스타일·터치 타깃 정상 복구
- **범위**: 이 stray 파일은 저장소(`project/`) **바깥의 로컬 환경 아티팩트**라 다른 개발 머신·Netlify 빌드에는 영향 없음
